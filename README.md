This is the simulation-backend of CHORAS. This repository implements the interfaces to different simulation methods.

Getting Started
===============

This repository is intended to be used as a part of the [CHORAS](https://github.com/choras-org/CHORAS) parent repository. To start using CHORAS, please refer to the respective [documentation pages](https://choras.readthedocs.io/en/latest/includes/setup.html)

Contributing
============

If you would like to contribute a simulation method to CHORAS, please check out our [contribution guidelines](https://choras.readthedocs.io/en/latest/includes/contributing.html)
